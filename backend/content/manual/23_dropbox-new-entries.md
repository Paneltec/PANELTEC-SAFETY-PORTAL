## Dropbox new-entry flags

Open **Settings → Dropbox** to browse the connected Dropbox files inside Paneltec. Open the folder you want to review, such as **Paneltec-General Administration**.

### Recognise new entries

- **NEW** identifies an entry detected since your last check of that folder.
- The seven-day badge identifies an entry first detected by Paneltec in the last seven days.
- **Since my last check** filters the current folder to entries you have not marked checked.
- **New in last 7 days** filters the current folder by when Paneltec first detected each entry.
- Select **All** to return to the full folder listing.

These flags apply to files and folders in the folder you are viewing. They describe newly detected entries, not changes to the contents of an existing file.

### Mark a folder checked

1. Open the folder and review the entries marked **NEW**.
2. Select **Mark this folder checked**.
3. The personal check time advances for that folder. Entries already observed are no longer new to you; entries detected later can still appear as new.

Your check is personal: it does not clear another user's review flags. It does not delete, move or change Dropbox files. A seven-day badge can remain after you mark a folder checked because it records recent detection separately.

### When tracking starts

The first time a folder is tracked, its existing entries become the starting baseline and are not all labelled new. Later entries are detected when Paneltec lists that folder. This is not a continuous background scan of every Dropbox folder.

> Note: “New in last 7 days” means first detected by Paneltec during that period. It is not a guaranteed Dropbox creation date. Review other folders separately to find their new entries.
