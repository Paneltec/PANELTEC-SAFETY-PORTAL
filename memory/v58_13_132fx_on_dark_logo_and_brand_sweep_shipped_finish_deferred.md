## Task A — On-dark logo on the PDF navy header

`backend/pdf_chrome.py` renders every generated PDF's top band as
navy (`self.setFillColor(NAVY)` L106). It was drawing the standard
grey+orange `/brand/logo-wordmark-960.png`, whose grey "THE" /
"GROUP" letters are nearly invisible on navy (Stephen's screenshot).

Fix: swap the default-logo fallback to the on-dark
`/brand/logo-wordmark-white-960.png` variant generated in `.132ft`.
When an org sets a custom `logo_url` we still respect it (light-logo
customers stay light). Also updated the text-only wordmark fallback
"CIVIL" → "GROUP" for the same brand consistency.

Other logo callers audited:
- Cover.jsx already uses `onDark` (`.132ft`).
- AppShell header/sidebar are light backgrounds — no change needed.
- Admin console PIN modal — no logo in its DOM.
- Email templates — plain-text only, no logo image.
