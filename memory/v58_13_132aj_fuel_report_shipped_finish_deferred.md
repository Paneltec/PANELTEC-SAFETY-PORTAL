## Fix 1 — Empty-state banner

**Backend (`fleet_fuel_reports.py`):**
- `_aggregate()` now computes `totals.latest_txn_date_iso` + `totals.latest_txn_timestamp` via one indexed `find_one({org_id, deleted_at:None}, sort=[timestamp,-1])` — unbounded by the current range, so it survives an empty filter. Powers the banner.

**Frontend (`FuelReporting.jsx`):**
- When `totals.fills === 0`, render a blue-2 banner ABOVE all other bands with:
  - Fuel icon avatar

  - Quick-jump preset pills: `Last week` · `This month` · `Year to date` (call `applyPreset(k)`)
  - Admin-only solid blue **"Import Fuel CSV"** button that opens the existing `FuelImportModal` (imported from `../components/FuelImportModal`, same instance the FleetRegister uses)

test-ids: `fuel-reporting-empty-state`, `fuel-reporting-empty-latest-date`, `fuel-reporting-empty-jump-last-week` / `-this-month` / `-ytd`, `fuel-reporting-empty-import-csv`.

## Fix 3 — CSV export enhancement

**Backend (`fleet_fuel_reports.py::fuel_report_export`):**
- Prepend a metadata block to every export:
  ```

  Scope,<scope>
  Period,<period>

Anomaly flags joined by `|`.
- Detail-mode filename: `fuel-report-detail-<scope>-<period>.csv`.

**Frontend (`FuelReporting.jsx`):**
- New second "**Export detail (per fill)**" button next to the existing "Export CSV" button. Calls `exportCsv(true)`.

test-ids: `fuel-reporting-export-csv`, `fuel-reporting-export-csv-detail`.

## Fix 4 — SmartFill Auto-sync visibility card

**Backend:** *No new endpoints needed.* Existing endpoints reused:
- `GET /fleet/fuel/smartfill-status` — returns `{last_synced_at, last_batch_summary, rate_limit_state, auto_sync_enabled, cron_registered}`.
- `POST /fleet/fuel/sync-smartfill` — admin manual trigger.
- `POST /fleet/fuel/smartfill-auto-sync` — admin toggle.
- Cron scheduler `cron_smartfill_auto_sync.py` — daily 06:00 Australia/Brisbane, registered at process start if `SMARTFILL_AUTO_SYNC_CRON=1`. Env var currently NOT set (intentional — pipeline validation still pending per your backlog).

**Frontend (`FuelReporting.jsx`, new `<SmartFillSyncCard>`):**
- Renders at the very top of the page, between the header and the filter chips.
- Status pill: `ENABLED` (emerald), `MANUAL ONLY` (amber — toggle ON but cron env var missing), `DISABLED` (slate).
- Body: `Last synced: <DD/MM/YYYY HH:mm> · +<inserted> · <dup> dup · <anom> anom` plus contextual line:
  - `Runs daily at 06:00 Australia/Brisbane.` when fully wired.
  - `Toggle is ON, but the cron scheduler isn't wired in this environment (SMARTFILL_AUTO_SYNC_CRON not set). Sync-now still works.` for the current MANUAL ONLY state.
  - `Manual only — auto-sync is off.` when toggle is off.
  - Rate-limit budget line when the endpoint returns `remaining`.
- Admin actions: **Sync now** (blue solid, POSTs `sync-smartfill`, toasts insertion counts, reloads report + status) and **Enable/Disable auto-sync** (toggle text depending on current state).
- Non-admins see status only, no buttons.
- Graceful fallback if `/smartfill-status` 500s: card degrades to `SmartFill status unavailable — <error>` without breaking the page.

test-ids: `fuel-reporting-smartfill-card`, `fuel-reporting-smartfill-status-pill`, `fuel-reporting-smartfill-last-synced`, `fuel-reporting-smartfill-sync-now`, `fuel-reporting-smartfill-toggle`.

## Fix 5 — Top 5 relabel + resort

**Backend (`fleet_fuel_reports.py::_aggregate`):**
- New `top_by_fill_litres` — per-fill rows sorted by `-litres, -timestamp`. First 5. Includes provisional rows (metric here is volume, not price). Fields: `key, label, litres, total_price, dpl, date_iso, timestamp, price_source, registration, driver`.

- Legacy `top_dpl_outliers` kept intact for the PDF renderer's `TOP 5 · $/L OUTLIERS` block (line 443 of the same file). Zero-regression.

**Frontend (`FuelReporting.jsx`):**
- Panel title: **"Top 5 · Highest fills"** with muted subhead `per-transaction · litres desc`.
- Table columns: `Litres · Vehicle · Driver · Date · Cost · $/L` (provisional $/L styled italic amber with `*`).
- Secondary panel: **"Top 5 · $/L outliers · procurement signal"** with subhead `real prices only` — rendered ONLY when `top_dpl_outliers_real.length > 0`. Suppresses the noise when every row is on the $3.00 placeholder.

test-ids: `fuel-reporting-highest-fills`, `fuel-reporting-highest-fill-{i}`, `fuel-reporting-outliers-real`, `fuel-reporting-outlier-real-{i}`.
